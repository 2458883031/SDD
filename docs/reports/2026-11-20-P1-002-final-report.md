## 四、交付内容摘要

### 4.1 任务分类

- 9 类任务：技术咨询、简单修改、Bug 修复、功能开发、系统重构、新项目、测试、部署、文档。
- L1/L2/L3 复杂度：影响范围、技术风险、依赖、不确定性、跨模块、数据/安全、生产环境。
- 信息不足 → `needs_input`；无法判断 → L3 + 人工确认；用户要求简化 → 不得跳过 G4/G5、安全控制、G6/R3/R4/SA。
- 高风险升级：生产部署、生产数据破坏、认证/授权/加密、敏感凭证、外部依赖。

### 4.2 Workflow

- 9 类 Workflow + 1 个 Subworkflow 组合示例。
- 动态选择、组合、跳过、追加、条件分支、终止、恢复。
- Requirements 与 Analysis 默认串行；G4 与 G5 可并行但必须同版本；多模块按路径/依赖拆分；并行失败按门禁/关键路径传播。

### 4.3 Task 与状态机

- Task 模型包含 task_id、run_id、workflow/node、task_type、status、context_status、inputs/outputs、dependencies、assigned_agent/skill、retry/timeout、risk/permission、approval、evidence、idempotency、lease、timestamps。
- Task Execution State：PENDING/READY/RUNNING/WAITING/BLOCKED/SUCCEEDED/FAILED/CANCELLED。
- 明确与 ADR-005 `task-status` 的映射，不替代 ADR-005。
- 终态不可原地恢复；重试创建新 Task 并关联 `parent_task_id`。

### 4.4 Gate / Approval

- GateDecision 不可原地修改；重新评估创建新 decision。
- G4/G5 必须同 subject hash；不得用 Task SUCCEEDED 代替 GateDecision。
- G6 仅实际生产部署触发；生产部署 R3+G6+SA；非生产部署不触发 G6。
- 生产数据库普通迁移 R3；破坏性操作 R4+SA；涉及生产部署时再加 G6。
- Approval 单次使用，绑定 task/operation/target/scope/subject hash/有效期；过期、失效、拒绝后不得复用。
- Agent 不得自批高风险操作；超时/沉默不等于批准。

### 4.5 失败、上下文与证据

- 失败分类：retryable/non_retryable/needs_human/needs_replan/terminal。
- 重试有预算、退避和幂等键；不可逆/非幂等操作不得自动重试。
- 上下文分层：User Input、Workflow Context、Task Context、Skill Input/Output、Artifact、Evidence。
- Evidence 记录输入/输出引用、actor、Skill/Tool、subject hash、Gate/Approval、时间、失败/恢复；统一脱敏。
- 日志、事件、审计区分；观测指标覆盖成功率、失败率、重试率、阻塞/审批等待、Gate 通过率、取消率。

### 5.3 负向测试结果

- Schema 负向 18：缺必填字段、未知字段、非法状态、非法依赖、SUCCEEDED 无输出、PASSED 无 subject hash、G6 无 subject hash、Approval APPROVED 无决定人、非法 Gate/Evidence 类型、Evidence 未脱敏等。
- DAG 负向 6：未知依赖、循环、重复节点 ID、无 end、Skill 节点缺 skill、未知 subworkflow。
- 状态机非法转换 116：终态不可恢复、PENDING 不得直接 RUNNING、CANCELLED 不得恢复、REJECTED 不得变 APPROVED 等。

### 5.4 Gate 测试结果

- 普通开发不触发 G6。
- 非生产部署不触发 G6。
- 生产部署必须 G6 + R3 + SA；缺 SA 或 R3 失败。
- 生产数据库普通迁移 R3，不触发 G6。
- 生产数据库破坏性操作 R4 + SA；涉及生产部署时加 G6。
- R4 不自动等于 G6；SA 不替代权限检查。
- Builder Check 作者自审失败，独立审查通过。

### 5.5 状态机测试结果

- 5 个状态机全部结构合法、初始/终态可达。
- 76 个合法转换全部通过。
- 116 个终态非法转换全部拒绝。
- 终态不可恢复、取消不可继续、审批拒绝不可转批准。

### 5.6 并行测试结果

- 无依赖任务可并行；依赖未满足不得启动。
- 循环依赖拒绝；DAG 正向 10 个。
- G4/G5 同 hash 通过；不同 hash、任一失败、仅 Task SUCCEEDED 均不通过。
- 新 commit 使旧 Gate 失效。
- 聚合 all/any/quorum；共享路径冲突检测；门禁相关分支失败使 Workflow 失败，独立分支失败不得报告为完全成功。

### 5.7 安全测试结果

- 未声明 Tool 拒绝；跨 Task 路径拒绝；R0 不得绕过到 R4。
- Approval 不得跨 Task/操作/产物复用；过期/拒绝不得使用。
- 秘密扫描覆盖 GitHub/OpenAI/AWS/私钥/password 赋值；示例无真实凭证。
- 证据必须 `redacted=true`。
- 子 Agent 只能获得权限子集，R4 不得转授。
