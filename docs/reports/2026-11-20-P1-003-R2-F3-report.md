## 二、F3-A：resolved 证据校验

### 2.1 修复

`resolved_evidence_exists()` 已移除将 `facts[].statement` 自动加入 evidence 集合的行为。现在只接受：

- `facts[].evidence_refs`；
- `analysis.source_refs`（`path@version#sha256` 或 path）；
- `candidate_solutions[].evidence_refs`；
- `risk_assessment[].evidence_refs`。

`user_stated` / `assumption` 的普通 statement 不再单独构成解决证据；只有明确 evidence_refs 才能证明 resolved。

### 2.2 新增测试

**负向 4 个：**

1. user_stated statement 直接作为 resolution evidence：拒绝；
2. assumption statement 直接作为 resolution evidence：拒绝；
3. 不存在的 evidence ref：拒绝；
4. 只存在 statement、没有 evidence_refs 的事实：拒绝。

**正向 4 个：**

1. facts.evidence_refs 中存在真实引用：通过；
2. source_refs 中存在真实引用：通过；
3. risk_assessment.evidence_refs 中存在真实引用：通过；
4. candidate_solutions.evidence_refs 中存在真实引用：通过。

`resolved_negative=4`，`resolved_positive=4`。

Schema 无需修改：`resolved` 已要求非空 `resolution_evidence_refs`；本轮只收紧引用语义。

## 三、F3-B：Acceptance Criterion retained

### 3.1 修复

`retained_actual()` 对 `acceptance_criterion` 要求：

- `next_steps.design_considerations` 中存在 `AC-<id>: <consideration>` 或精确 `AC-<id>`；
- 仅任意非空字符串、无关内容不通过；
- 保持 `source_type=acceptance_criterion` + `source_id` 追踪。

标准/SKILL/checklist 已同步说明该格式。Schema 无需新增字段：`retained` 已可用，`design_considerations` 已存在。

### 3.2 新增测试

**正向 1 个：**

- Acceptance Criterion retained → `AC-1: 组合筛选验收标准需映射到测试设计`：通过。

**负向 2 个：**

- Acceptance Criterion retained，但 design_considerations 为空：拒绝；
- Acceptance Criterion retained，但只引用无关内容：拒绝。

`acceptance_retained_negative=2`，`acceptance_retained_positive=1`。
