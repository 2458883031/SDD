## 二、F1：Requirements → Analysis 信息完整性

### 2.1 实现

在 `data.analysis` 增加：

```text
requirements_traceability.items[]
  - source_type
  - source_id
  - disposition
  - analysis_refs[]
  - rationale
```

覆盖上游：

- FR / NFR；
- constraints；
- dependencies；
- assumptions；
- unknowns（含非阻塞）；
- open_questions；
- acceptance_criteria；
- non_goals；
- source_refs。

`disposition`：

- `analyzed`：已纳入分析；
- `mapped`：映射到候选方案/风险/设计考虑，必须有 `analysis_refs`；
- `retained`：保留为假设/未知项/问题/非目标；
- `resolved`：已解决；
- `not_applicable` / `deferred`：必须有 rationale。

### 2.2 规则

- 不要求机械复制上游内容；只要求逐项建立处理/追踪关系。
- 不允许静默删除；缺失 trace 项校验失败。
- 不修改 Requirements Artifact；不把 Analysis 变成第二个 Requirements 生产者。
- 不新增全局 Artifact 类型或状态机。

### 2.3 测试

**负向 8 个：**

1. 删除上游 Dependency trace；
2. 删除非阻塞 Unknown trace；
3. 删除 Acceptance Criteria trace；
4. 删除关键 FR trace；
5. 删除关键 NFR trace；
6. 删除 Non-goal trace；
7. 删除 Constraint trace；
8. `mapped` 项没有 `analysis_refs`。

另加 Schema 负向：

- 缺少 `requirements_traceability`；
- `not_applicable` 缺 rationale。

**正向 1 个：**

- 将非目标标记 `not_applicable` 且提供 rationale，允许通过。

`f1_negative=8`，`f1_positive=1`。

## 三、F2：全状态 Requirements Artifact 来源绑定

### 3.1 实现

`validate_analysis_output()` 将来源检查移到 `status != ok` 提前返回之前：

```text
if data.analysis exists and input.requirements_ref exists:
    source_requirements_ref == input.requirements_ref
```

适用于：

- `ok`；
- `needs_input`；
- `needs_approval`；
- `blocked`；
- 包含 `data.analysis` 的 `failed`。

没有 `data.analysis` 的失败输出不要求存在分析 Artifact。不得通过删除部分分析内容绕过来源校验。

### 3.2 测试

`f2_cases=8`：

1. needs_input 来源一致：通过；
2. needs_input 来源不一致：拒绝；
3. blocked 来源一致：通过；
4. blocked 来源不一致：拒绝；
5. needs_approval 来源不一致：拒绝；
6. ok 来源不一致：拒绝；
7. failed 含 analysis 来源一致：通过；
8. 部分分析无 Artifact：允许。

## 四、F3：Analysis Artifact 完整性

### 4.1 实现

- `status=ok` 的 `artifacts` 至少包含一个 `type=analysis` 的 Artifact。
- Artifact 必须符合 ADR-005 的 path/version/sha256/type。
- 不允许用 `source_refs` 替代 `artifacts`。
- `needs_input`/`blocked` 等部分分析可按实际产物决定是否生成 Artifact，但不得伪造完成的分析 Artifact。

### 4.2 测试

`f3_cases=2`：

- ok 无 analysis Artifact：拒绝；
- ok Artifact type 非 analysis：拒绝；
- 部分分析无 Artifact：允许（F2 用例 8）。
