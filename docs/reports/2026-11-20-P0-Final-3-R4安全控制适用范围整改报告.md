## 一、执行摘要

P0-Final-3 关闭 R4 安全控制“一刀切”问题：

1. **读取敏感凭证**：R4 + SA + 安全审查 + 密钥管理/最小权限/凭证防泄漏 + 审计；不再无条件要求业务数据备份/恢复。
2. **不可逆高危操作**：R4 + SA + 安全审查 + 适用备份/恢复 + 审计。
3. **R4 高风险 Shell**：必须 SA + 安全审查 + 审计；涉及数据破坏/不可逆变更时增加适用备份/恢复；涉及敏感凭证时执行密钥管理/最小权限/防泄漏；不再把备份作为所有 R4 Shell 的无条件要求。
4. R2/R3 Shell 分类、R0–R4 定义、G6 规则均未改变。
