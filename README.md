# SDD - Software Development Skills

面向多 Agent 平台的模块化、可编排、可验证的软件研发能力体系。

## 项目定位

SDD 不是简单的 Skill 集合，而是一套完整的软件研发方法论，让 AI Agent 能够执行从需求澄清到部署上线的完整研发流程。

### 核心原则

- **架构统一** — 六层架构，职责清晰
- **能力模块化** — 专业 Skill 独立复用
- **流程动态编排** — 根据任务类型自动选择流程
- **平台适配解耦** — 核心能力与平台差异分离
- **质量自动验证** — HARD-GATE 门禁确保质量
