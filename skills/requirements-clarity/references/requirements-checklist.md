# 需求检查清单

用于 `requirements-clarity` 自检：

- [ ] 目标能用一句话复述；
- [ ] 范围（包含）已列出；
- [ ] 非目标（不包含）已列出；
- [ ] 约束已分类：业务/技术/时间/安全/兼容性；
- [ ] 每条验收标准可观察、可验证；
- [ ] 没有“尽快/友好/高性能”等不可验证词；
- [ ] 与已有需求/上下文无冲突；
- [ ] 缺失信息已转为明确问题；
- [ ] 安全敏感项已标记 G/SA 建议；
- [ ] 未猜测缺失信息；
- [ ] 输出符合 Schema。

参考：[skill-io-contract.md](../../../docs/standards/skill-io-contract.md)
